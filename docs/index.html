X-ray any topic.

explain turns your project's architecture, a codebase, a concept, a technology, or a process into a visual explainer. A diagram sits at the core, every fact is checked, and anything that could not be checked is marked.

Honest by design

An explainer is only useful if you can trust it.

Checks before it claims

For a project, it reads the repository and runs read-only status commands. Anything recent or numeric gets a primary source and a link.

Marks what it can't confirm

Every part carries a tag, so vision never passes for shipped code.

Read-only
